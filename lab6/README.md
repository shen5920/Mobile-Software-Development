# 光影集 - 微信云开发小程序(实验 6)

一个基于微信小程序云开发的照片分享社区:用户可以上传照片、点赞、评论、浏览他人主页。

## 功能清单

- **登录(头像昵称)**:「个人」Tab 未登录时展示登录卡,选择微信头像 + 输入昵称即登录;
  上传入口只在首页,未登录点上传会引导先去登录;登录后「个人」Tab 变为完整个人主页
  (资料、作品数/获赞、作品管理),可随时"编辑资料"
- **底部导航**:「首页」照片流 + 「个人」我的主页两个 Tab;点自己头像/名字直接切到个人 Tab,
  点别人的头像/名字则进入"TA 的主页"
- **开屏动画**:冷启动播放"相机对焦 → 红灯闪烁 → 咔嚓(快门音效+震动) → 白闪淡出",
  动画期间自动隐藏底部导航铺满全屏,白色消散后无缝揭示首页并恢复导航;点击屏幕可跳过
  (音效: `miniprogram/assets/audio/shutter.wav`)
- **照片流首页**:骨架屏加载、下拉刷新、上拉无限加载、图片懒加载、相对时间显示
- **发布照片**:选择相册/相机图片、发布前预览、真实上传进度条、发布后自动返回
  (需先登录;资料记录在登录时写入,作品会带上当时的头像昵称快照)
- **点赞**:双击图片点赞(爱心动画)或点按钮点赞,服务端幂等计数,失败自动回滚
- **评论**:评论区、发布/删除自己的评论(删除照片时评论级联清理)
- **个人主页**:作品数、获赞总数(云函数聚合)、作品瀑布流,无作品时也能通过导航参数展示资料
- **浏览统计**:每次进入详情页记录浏览量
- **用户资料**:微信官方头像昵称填写能力(chooseAvatar + nickname),头像转存云存储避免临时链接失效;未设置时用"光影旅人"+ 渐变字母头像兜底
- **删除**:作者本人删除照片(数据库记录 + 云存储文件 + 全部评论一次清理)
- **分享**:详情页可分享好友/朋友圈,分享卡片使用 https 临时链接

## 云端配置步骤(重要)

1. **环境 ID**:在 `miniprogram/app.js` 的 `globalData.env` 填入你自己的云环境 ID
   (微信开发者工具 → 云开发控制台 → 设置 → 环境 ID)

2. **创建集合**:云开发控制台 → 数据库 → 创建集合 `photos` 和 `comments`

3. **集合权限**(两个集合都设为):
   `所有用户可读, 仅创建者可写`
   原因:客户端只做"读"和"创建自己的文档";点赞/取消赞/浏览/删除等跨用户写操作
   全部经由云函数 `interactPhoto` 以管理员身份执行,不受该权限限制。

4. **部署云函数**(共 2 个,右键云函数目录 → 上传并部署:云端安装依赖):
   - `cloudfunctions/getOpenid` — 获取用户 openid(启动时自动调用)
   - `cloudfunctions/interactPhoto` — 点赞/取消赞/浏览量/删除/主页统计

5. **真机调试建议**:若提示隐私相关失败,检查 app.json 中 `"__usePrivacyCheck__": false`
   是否保留(实验演示可关闭隐私弹窗);开发者工具中勾选
   "不校验合法域名、web-view(业务域名)、TLS 版本以及 HTTPS 证书"。

## 数据字段说明

**photos 集合**(每条照片记录):

| 字段 | 说明 |
| --- | --- |
| photoUrl | 云存储 fileID(原图) |
| avatarUrl | 作者头像(cloud:// 或 https,空则前端显示字母头像) |
| nickName | 作者昵称 |
| province / country | 所在地区(旧版 getUserInfo 采集,可能为空) |
| description | 照片描述(≤100 字,可为空) |
| addDate | 发布日期 YYYY-MM-DD(展示兼容旧数据) |
| createTime | 发布毫秒时间戳(新排序字段,旧数据无此字段时自动排后面) |
| likes / likedBy | 点赞数 / 点赞者 openid 数组 |
| views | 浏览量 |

**comments 集合**(每条评论记录): photoId / content / nickName / avatarUrl / createTime
(客户端创建时自动写入 `_openid`,删除自己评论走客户端,级联删除走云函数)

## 常见问题排查

- 出现"云端功能未就绪"弹窗 / 保存资料提示失败 / 发布提示网络异常
  → 云函数没部署或环境 ID 不对: 检查 app.js 的环境 ID, 并把 `getOpenid`、`interactPhoto`
  两个云函数都"上传并部署: 云端安装依赖"。修复后重启小程序即可(openid 会自动重试并缓存)。
- 点赞无反应 → 确认 `interactPhoto` 已部署且数据库集合存在
  (点赞不再依赖客户端登录状态, 身份由云函数服务端识别)
- "我的点赞"为空/点赞数正确但不显示 → 点赞列表由云函数 `interactPhoto` 的 `myLikes` 动作
  查询(不受集合权限限制), 需要**重新部署 interactPhoto**; 同时建议把 `photos` 权限设为
  "所有用户可读, 仅创建者可写", 否则首页也看不到别人的照片
- 首页列表为空且报权限错误 → 检查集合权限是否已设为"所有用户可读"
- 图片不显示 → 确认云存储可用, 文件未在控制台被误删
- 上传失败 → 检查是否已上传云函数、环境 ID 是否正确
